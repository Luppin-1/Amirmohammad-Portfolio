# AmirMohammad Ehsani — Portfolio

A modern and animated personal portfolio built with React and Vite.

This website introduces my skills, selected projects, academic journey, technical courses, and achievements as a Computer Engineering student and aspiring Front-end Developer.

## Features

- Modern responsive design
- Persian and English languages
- Full RTL and LTR support
- Dark and light themes
- Smooth scroll-based animations
- Animated hero section
- Interactive project cards
- Responsive mobile navigation
- Downloadable resume
- Direct links to GitHub projects
- Reduced-motion accessibility support
