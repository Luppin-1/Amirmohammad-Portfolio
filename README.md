# AmirMohammad Ehsani — Portfolio

A modern, animated, bilingual portfolio built with React, Vite, and Tailwind CSS.

The website presents my front-end skills, selected projects, academic journey, technical courses, achievements, and contact information.

## Live Demo

**[View the live portfolio](https://luppin-1.github.io/Amirmohammad-Portfolio/)**

The production website is hosted on GitHub Pages and deployed automatically with GitHub Actions.

## Features

- Fully responsive layout for mobile, tablet, laptop, and desktop
- Persian and English languages
- Complete RTL and LTR support
- Dark and light themes
- Animated hero section and loading screen
- Smooth scroll and reveal animations
- Interactive skill, project, course, and contact cards
- Responsive mobile navigation
- Downloadable resume
- Direct links to GitHub projects and social profiles
- Reduced-motion accessibility support
